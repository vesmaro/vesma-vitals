## Правила

1. Обновление реестра — тем же PR, что вводит/меняет метрику или обещание.
2. Правило сиротской метрики: метрика без дашборда / алерта / claims-ссылки
   удаляется на квартальном ревью.
3. Продвижение вердикта в merge-гейт — только новой директивой владельца
   с перепрепрегистрацией (методология §1).
4. `UNMEASURED` — честный статус по духу ADR-0021: отсутствие данных
   никогда не рендерится зелёным.
